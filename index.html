API Catalogus Frankrijk

Naslagwerk voor de Franse API’s achter de tools van Communities Abroad. Niet alleen wat een API doet, maar ook wat je moet weten voordat hij werkt: sleutelregels, limieten, abonnementstermijnen en de valkuilen die anders een middag kosten. Alles komt uit apis.json.

In deze catalogus staat geen enkele sleutel, token of application-ID, ook niet gedeeltelijk. Waar een sleutel nodig is, staat beschreven hoe je hem krijgt.
